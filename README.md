# الدحيح
1. ارفع محتوى المجلد على repo **Public** في GitHub.
2. Actions → **Build Android APK** → Run workflow → نزّل `aldahih-apk` من Artifacts وثبّت `app-debug.apk`.
3. **Update episodes** بيشتغل كل 6 ساعات ويضيف الحلقات الجديدة للـ repo (التطبيق بيقرأها بدون إعادة بناء).

ضبط مواعيد النزول: أول `www/releases.js` (`REL`). السرعة والتحميل: `native/YtDlpPlugin.java`.
