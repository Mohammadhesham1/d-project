# الدحيح
1. ارفع محتوى المجلد على repo **Public** في GitHub، وضيف secret باسم `YT_API_KEY`.
2. أول ما ترفع، **Build Android APK** بيشتغل لوحده: بيجيب كل حلقات AJ+ ويحفظها في الـ repo ويبني الـ APK. نزّل `aldahih-apk` من Actions ← آخر تشغيل ← Artifacts.
3. **Update episodes** بيحدّث الحلقات كل 6 ساعات لوحده، والتطبيق بيقرأها من الـ repo.

مواعيد النزول: أول `www/releases.js`. التحميل: `native/YtDlpPlugin.java`.
